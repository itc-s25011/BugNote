# BugNote（エラー解決メモ帳）

## 1. アプリの概要
プログラミング学習やWebアプリ開発中に遭遇したエラー内容と、その原因・解決手順を記録し、後から素早く検索できるナレッジベースアプリです。

## 2. 機能仕様
- **トップページ (`/`)**: アプリの概要説明および最近追加した解決メモ3件のピックアップ表示
- **エラーメモ一覧ページ (`/memos`)**:
  - 登録されているエラー解決メモの一覧表示
  - **キーワード検索機能**: エラーメッセージや技術名を対象とした全文検索（`?q=` パラメータ連携）
  - **ページネーション機能**: 1ページあたり3件表示のページ送り機能（`?page=` パラメータ連携）
- **エラーメモ詳細ページ (`/memos/[id]`)**: 選択したエラーのタイトル・登録日・技術カテゴリ・解決手順の表示

## 3. 使用技術
- **フレームワーク**: Next.js (App Router) / TypeScript
- **スタイリング**: globals.css / CSS Modules
- **CMS / データ管理**: microCMS (`microcms-js-sdk`)
- **デプロイ**: Vercel
- **ソース管理**: Git / GitHub
